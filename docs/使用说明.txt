安卓救援宝 DroidRescue — 安卓手机/平板投屏控制 + 碎屏盲操救援
==============================================================

运行
----
双击 DroidRescue.exe 即可，无需安装。adb、scrcpy-server、解码库都已内置，
首次运行自动解压到 %LOCALAPPDATA%\DroidRescue。
（从旧版 padctl 升级：已保存的密码、机型配置、窗口位置会自动迁移。）

系统要求：Windows 10/11 64 位，显卡支持 DirectX 12。

macOS（12 及以上，Apple 芯片）：打开 dmg，把「DroidRescue」拖进「应用程序」。
首次打开请右键 →「打开」（暂未做开发者签名）。数据目录为
~/Library/Application Support/DroidRescue；锁屏密码用钥匙串里的密钥加密。
macOS 救援不需要安装任何驱动、也不会请求管理员权限。


普通使用（设备已开启 USB 调试）
------------------------------
1. 用数据线连接设备，在设备上允许 USB 调试。
2. 02 投屏 →「开始投屏」。鼠标=触摸，滚轮=滑动，右键=返回，中键=主页，
   点击画面后键盘直接输入。
3. 若看不到设备：可能缺少 ADB USB 驱动，安装 Google USB Driver
   （或 vivo 办公套件，它带有 ADB 驱动）后重新插拔。


救援模式（屏幕碎了 / USB 调试已关闭）
------------------------------------
不需要在电脑上安装或运行任何厂商软件。救援时可能弹出一次管理员确认
（为平板的 USB 接口绑定 Windows 自带的 WinUSB 驱动），点「是」即可；
同一台电脑、同一个 USB 口、同一种 USB 模式只需一次。

步骤：
1. 04 输入锁屏密码（不连接设备也可以先输入；勾选「记住」会用
   Windows DPAPI 加密保存，只在本机本账户有效）。
2. 插上设备，06 救援 →「一键救援：解锁并开启 USB 调试」。
   vivo Pad3 流程：唤醒 → 解锁 → USB 用途选「连接办公套件」（设备自行
   打开 USB 调试）→ 关闭提示 → 勾选一律允许 → 允许。
3. 完成后设备以已授权的 adb 设备出现，直接开始投屏。

机型：06 救援 →「机型」自动选择（按型号；新电脑上没见过的设备按 USB
接口识别）。内置 vivo Pad3（完整流程）和通用 Android（仅解锁）。其他机型
可在「高级 → 编辑机型配置」里添加：unlock / enable 脚本，以及
usb = VID:PID:MI（救援用的 USB 接口，每种 USB 模式一个）。

救援不成功时：06 救援 →「高级 → 设备体检」列出电脑看到的 USB 接口、驱动
和 adb 状态，「复制报告」可发给技术支持；新机型的 usb = … 也从这里抄。


数据文件（%LOCALAPPDATA%\DroidRescue）
-------------------------------------
  droidrescue.log        日志
  passwords.dat          锁屏密码（DPAPI 加密）
  rescue-profiles.txt    救援机型配置
  known-devices.txt      序列号 → 型号
  window.ron             窗口位置

卸载：删除 DroidRescue.exe 和 %LOCALAPPDATA%\DroidRescue 文件夹。
